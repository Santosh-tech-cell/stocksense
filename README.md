# StockSense

A modern inventory management system built with Streamlit.

## Features
- Multi-tenant (per-user data isolation)
- Receipts, deliveries, transfers, adjustments
- Multi-warehouse support
- Live dashboard with KPIs and charts
- 5 themes, cursor aura, animations
- Demo account for instant preview

## Run locally
pip install -r requirements.txt
streamlit run app.py
